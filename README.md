
# ValidaGT Pro

Sistema web para registrar información, realizar validaciones
con expresiones regulares y aplicar restricciones de bases
de datos SQL.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL / MariaDB
- XAMPP
- Visual Studio Code

## Funcionalidades

- Panel de administración.
- Estadísticas de validaciones.
- Gráfico de aprobación y rechazo.
- Validación de teléfono de Guatemala.
- Validación del formato de DPI.
- Validación de correo electrónico.
- Restricciones NOT NULL, UNIQUE y CHECK.
- Registro de intentos aprobados y rechazados.
- Historial y búsqueda de registros.
- Modo oscuro y claro.

## Instalación local

1. Instalar XAMPP.
2. Copiar el proyecto en C:/xampp/htdocs/ValidaGT-Pro.
3. Iniciar Apache y MySQL.
4. Ejecutar sql/local.sql desde phpMyAdmin.
5. Copiar config/db.example.php como config/db.php.
6. Configurar los datos de conexión.
7. Abrir http://localhost/ValidaGT-Pro/.

## Seguridad

El archivo config/db.php es privado y no debe subirse
a repositorios públicos.

Esta aplicación es una demostración educativa.
Se deben utilizar solamente datos ficticios.

El formato de DPI no equivale a una verificación oficial.
